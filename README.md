# Трекер привычек

Офлайн-трекер привычек (MVP): серии, прощение пропусков, тепловая карта, статистика и заметки к дню.
Работает без сервера: данные хранятся в `localStorage` браузера. Приложение можно установить на телефон как PWA.

**Стек:** React 19, TypeScript, Vite, Tailwind CSS 4, Vitest, vite-plugin-pwa.

## Запуск

Нужен Node.js 20+ и npm.

```bash
npm install
npm run dev       # dev-сервер: http://localhost:5173
npm test          # unit-тесты (Vitest)
npm run build     # проверка типов и production-сборка в dist/
npm run preview   # локальный просмотр сборки (здесь работает service worker)
```

Чтобы открыть dev-сервер с телефона в той же сети: `npm run dev -- --host` и откройте адрес `Network` из консоли.
Установка как PWA и офлайн-режим работают в production-сборке (`npm run build && npm run preview`) по HTTPS или на `localhost`.

Сборка использует относительные пути и hash-маршрутизацию, поэтому содержимое `dist/` можно выложить на любой статический хостинг, в том числе в подпапку (например, GitHub Pages).

## Возможности

- **Привычки:** создание, редактирование, архивирование и удаление; название, эмодзи, цвет, частота (каждый день, по выбранным дням недели или N раз в неделю). Есть шаблоны для быстрого старта.
- **Экран «Сегодня»:** план на день, отметка одним тапом с анимацией, прогресс «3 из 5». Полоса дней позволяет отметить выполнение за последние 7 дней.
- **Серии:** текущая и лучшая. Невыбранные дни недели серию не прерывают.
- **Прощение пропусков:** через меню «⋯» день отмечается как «пропуск по уважительной причине». Такой день серию не обрывает и не снижает процент выполнения.
- **Тепловая карта** за 6 месяцев по каждой привычке. Нажмите на клетку, чтобы увидеть день.
- **Статистика:** выполнение за 7 и 30 дней (со сравнением с прошлым периодом), лучшие и худшие дни недели, сводка по привычкам, среднее настроение.
- **Заметка к дню:** настроение и короткий текст.
- **Темы:** системная, светлая и тёмная.
- **Экспорт и импорт** всех данных в JSON (Настройки → Данные). При импорте файл проверяется, текущие данные заменяются после подтверждения.

## Правила расчёта серий

| Частота | Единица | Увеличивает серию | Не влияет | Обрывает |
|---|---|---|---|---|
| Каждый день / дни недели | дни | выполненный день (в том числе вне графика, как бонус) | невыбранный день, уважительный пропуск, сегодняшний день без отметки | запланированный прошедший день без отметки |
| N раз в неделю | недели (Пн–Вс) | неделя с ≥ N выполнениями | текущая неделя, первая (неполная) неделя, неделя, где норма набирается только с учётом уважительных пропусков | прошедшая неделя с недобором |

Учёт идёт от даты создания привычки или от самой ранней отметки, если она раньше. У архивной привычки учёт заканчивается датой архивации.

## Структура

```
src/
  types.ts              Типы данных: Habit, Completion, DayNote, AppData
  utils/
    dates.ts            Даты как строки YYYY-MM-DD в локальной зоне (без проблем с часовыми поясами и летним временем)
    streaks.ts          Чистые функции: серии, «запланировано ли на день»
    stats.ts            Чистые функции: процент выполнения, дни недели, прогресс дня
    heatmap.ts          Построение тепловой карты
    format.ts           Склонения, подписи частоты, сортировка
    __tests__/          Unit-тесты
  storage/
    StorageAdapter.ts   Интерфейс хранилища (load/save/clear, асинхронный)
    localStorageAdapter.ts  Реализация на localStorage
    serialization.ts    Проверка и нормализация данных (загрузка и импорт)
    index.ts            Выбор активного адаптера
  state/
    reducer.ts          Чистый редьюсер всех изменений данных
    AppStore.tsx        React-контекст: загрузка, автосохранение, действия
  data/templates.ts     Шаблоны привычек
  components/           UI-компоненты (кнопка отметки, тепловая карта, шторка, пикеры…)
  screens/              Экраны: Сегодня, Привычки, Форма, Детали, Статистика, Настройки
  router.ts             Минимальный hash-роутер
  theme.ts              Применение темы
```

### Замена localStorage на API

UI и логика работают только с интерфейсом `StorageAdapter`. Чтобы перейти на сервер, реализуйте его (например, `apiAdapter.ts` с `fetch`) и подключите в `src/storage/index.ts`. Остальной код менять не нужно.

## Тесты

`npm test` запускает тесты в поясе `Europe/Berlin` (задано в `vite.config.ts`), чтобы ловить ошибки, связанные с переходом на летнее время. Покрыты:

- серии для всех типов частоты, уважительные пропуски, отметки до даты создания, архивация;
- границы месяцев, 29 февраля в високосном году, смена года, 53-я ISO-неделя;
- процент выполнения, статистика по дням недели, прогресс дня;
- тепловая карта, арифметика дат;
- редьюсер, валидация импорта, адаптер localStorage.
